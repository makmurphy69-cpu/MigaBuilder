What it finds

🔑 Keys and tokens
AWS, GitHub, GitLab, OpenAI, Anthropic, Google, Stripe, Slack, Discord and Slack webhooks, SendGrid, Twilio, npm, Hugging Face, Shopify, JWTs, private key blocks, Bearer and Basic headers, cookies, passwords in URLs and connection strings, and password=, token: or api_key values in .env, JSON and YAML.
👤 Personal data
Email addresses, phone numbers, IPv4 and IPv6 addresses, MAC addresses, card numbers (checked with the Luhn test), IBANs (checksum checked), Swedish personal ID numbers, US social security numbers, and user names in file paths like /home/anna or C:\Users\anna.
🔒 Private
Your text is never uploaded. The checks run in this page with JavaScript, so it also works offline once the page has loaded.

About Redact Forge

Redact Forge hides API keys, tokens, passwords, emails, IP addresses, phone and card numbers in logs and code before you paste them into an AI chat, a bug report or a forum.

How to use Redact Forge

  1. Paste a log, error message or config file, or press Try an example log.
  2. Press “Copy”.
  3. Check the highlighted replacements, copy the safe text, and paste the answer you get back into Put the real values back.

Can I get the real values back?

Yes. Paste the answer you get back into Put the real values back, and the placeholders are swapped for your real values.

Is Redact Forge free?

Yes. It is free to use, with no account, no watermark and no paywall.

Are my files uploaded?

No. It runs entirely in your browser, so your files and text stay on your device.

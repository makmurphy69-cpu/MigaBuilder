# Coloring library pictures

- `openmoji/*.svg` — line drawings from [OpenMoji](https://openmoji.org), the open-source emoji and icon project,
  licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Flag outlines (`*.svg` with a
  matching `*-color.svg`) were made from OpenMoji's colour flags. Coloring Forge prints the credit on every page.
- The "bold" pictures are drawn in the browser with Google's [Noto Emoji](https://fonts.google.com/noto/specimen/Noto+Emoji)
  font (SIL Open Font License 1.1); no font files are stored here.

Rebuild with `scripts/coloring-library/build.mjs` (instructions at the top of that file).

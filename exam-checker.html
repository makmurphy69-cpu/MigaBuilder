Exam Checker

Build an exam, print bubble answer sheets, photograph every student's paper and download everyone's marks.

Everything stays on this device: the exam, the photos and the marks are saved in this browser only. Use Backup to move an exam to another device.

How to use Exam Checker
  1. Build the exam — add each question in the same order as your paper and choose its type and points. Paste your class list (one student per line: ID, Name).
  2. Answer key — tap the correct bubble for each question, or photograph a sheet filled in with the correct answers.
  3. Print sheets — press Print one sheet per student. Every sheet has the student's name and a code printed on it.
  4. Test the reader — photograph a sheet with the correct answers. When it says 100%, you are ready.
  5. Mark students — photograph every sheet and drop all the photos at once, in any order. Each page is matched to its student automatically. Then press Next answer to check to see only the answers that need you.
  6. Results — check the class list for missing students, then download Excel or CSV, the class report or result slips.

Best way for a big class: printed-per-student sheets (step 3) mean you never type names, pages can be photographed in any order, and a sheet photographed twice is counted once. No class list? Use Student ID bubbles (step 1) — or keep each student's pages together, since the name is then only read from handwriting.

Tip: press Load demo exam, then try steps 4–6 with the demo buttons to see it all work in a minute.

Build the exam

Tip: add questions in the same order as your question paper. Multiple-choice and true/false answers are read from bubbles; short answers are read from the written box and compared with your accepted answers; open answers are shown to you as a picture so you can give the points.

Marking rules & grade scale
Class list (optional) — fills in names from the Student ID

One student per line: ID, Name. When a sheet's ID bubbles match, the name is filled in for you. Without IDs the list is used in order for demo and hand-typed students.

Answer key

Tap the correct bubble for each question, type the accepted short answers, or fill in one answer sheet with the correct answers and read it from a photo.

Short answers: separate accepted alternatives with |, e.g. Nairobi | Nairobi city. Numbers are compared as numbers (3.50 = 3.5). Open answers: add key words — the checker suggests points from the words it finds, and you decide.

Print the answer sheets

Give each student one answer sheet. The four black squares let the camera find the page, so the photo can be taken at an angle, on a desk, from a phone.

  • One sheet per student (from the class list in step 1) prints each student's name and a code along the bottom edge, so photos can be added in any order and never need a name typed.
  • Blank sheets work too: students write their name, and fill in the Student ID bubbles if you turned them on.
  • Print at 100% (actual size) if you can — but the reader still works if the printer shrinks the page.
  • Students fill bubbles completely with a dark pen or pencil and write short answers clearly inside the boxes.
  • To mark, lay the sheet flat in good light and take the photo so all four black squares are visible.

Test the reader — correct-answer checker

Before marking the class, take a photo of an answer sheet filled in with the correct answers (print the filled key or fill one by hand). The checker reads it and compares each answer with your key, so you can see that the system gets it right.

    About Cipher Forge

    Cipher Forge turns messages into secret codes and back again. Pick a code, type your message and send the result, together with the decoding instructions, to a friend. It can read a coded note from a photo, crack a shift code when you don't know the number, and hide a message invisibly inside a photo.

    How to use Cipher Forge

    1. Choose “Make a code”, pick a secret code and type your message.
    2. Copy the result, save it as a picture, or share a link that opens ready to decode.
    3. To read one, choose “Decode”, pick the code (or press “Crack it”) and paste the message or read it from a photo.

    Which secret codes can it make?

    Caesar shift (any number), ROT13, Atbash (backwards alphabet), Vigenère (keyword), number code (A=1), Morse code, Pigpen symbols, phone keypad, binary, backwards writing and the rail fence zig-zag. Each one comes with instructions for decoding it by hand.

    Can it decode a message when I don't know the code?

    Yes. Press “Crack it” and it tries every shift and every simple code, then shows the answers that read most like real words first. Keyword codes like Vigenère need the keyword.

    How does hiding a message in a photo work?

    The message is stored in tiny colour changes that you cannot see. The photo looks the same, but Cipher Forge can read the message back. Add a password to lock it. Send the PNG as a file: apps that compress photos destroy the hidden message.

    Are these codes safe for real secrets?

    These are classic puzzle codes for fun, games and learning. Anyone patient can crack them, as the “Crack it” button shows. A photo message locked with a password uses real encryption (AES-256), so keep the password strong.

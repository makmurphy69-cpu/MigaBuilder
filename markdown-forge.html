About Markdown Forge

Markdown Forge is a free online Markdown editor with a live preview. Write with the toolbar or keyboard shortcuts, use tables, task lists and code blocks, turn Word documents and web pages into Markdown, and export your text as a .md file, an HTML page or a PDF.

How to use Markdown Forge

  1. Type Markdown on the left, or open a file.
  2. Watch the formatted result appear on the right as you type.
  3. Download it as .md, HTML or PDF, or copy it as formatted text.

What is Markdown?

Markdown is a simple way to format text with ordinary characters: # for a heading, **bold**, *italic*, - for a list and [text](link) for a link. It is used on GitHub, in README files, notes apps, chat apps and many websites.

Can I turn a Word document or web page into Markdown?

Yes. Open a .docx file, or copy text from Word, Google Docs or a web page and paste it into the editor. Headings, lists, links, bold text and tables become Markdown.

Is my text saved?

Your text is saved automatically in this browser only, so it is still there when you come back. It is never uploaded to MigaBuilder.

Yes. It is free to use, with no account, no watermark and no paywall.
